# Plan d'entrée GeeN (preuve par exécution)

## Intention
Passer de "prise de contact" à "partenaire évident" sans relance commerciale prématurée.

Principe : arriver avec une preuve concrète de niveau (prototype), puis ouvrir la discussion sur la mission.

---

## Stratégie
- Ne pas recontacter immédiatement avec un devis.
- Construire un artefact de qualité qui démontre : direction visuelle, architecture, crédibilité UX.
- Respecter le prérequis client : globe en mouvement.

---

## Plan d'action (ordre)

### 1) Construire un mini prototype (72h max)
Livrable : landing "avant/après" (desktop + mobile), style premium et épuré, motion limitée.

Inclure :
- Hero fort (promesse claire + CTA principal)
- Globe animé intégré dès le hero
- Hiérarchie narrative propre (promesse -> bénéfices -> preuves -> action)

### 2) Faire une démo ciblée (pas une refonte complète)
Objectif : montrer la capacité d'exécution sans surproduire.

Périmètre recommandé :
- Hero finalisé
- Section "Pourquoi GeeN"
- Section "Preuves sociales"
- Footer public nettoyé (sans bruit BuddyBoss)

### 3) Préparer un package de présentation net
- 3 captures (hero, preuves, mobile)
- 1 vidéo courte (30-45 s) : globe + transitions sobres
- 1 note UX (pourquoi cette structure convertit mieux)
- 1 note "Phase 2" (ce qui sera traité ensuite)

### 4) Envoyer un message de contribution (pas de vente)
Angle : "J'ai avancé sur une proposition concrète alignée à vos références".

Contenu de l'envoi :
- lien démo/prototype
- captures
- vidéo
- note UX courte

### 5) Cadrer la mission uniquement après signal positif
- Étape 1 payante : production landing
- Étape 2 : refonte progressive plateforme (inscription/login, nettoyage public, séparation public vs membre)

---

## Critères de qualité avant envoi
- Cohérence avec les 2 références transmises
- Globe animé présent mais non envahissant
- Mobile propre et lisible
- CTA principal dominant
- Aucune sensation "WordPress brut" dans la démo

---

## Message type (à utiliser quand prêt)

Bonjour Manuella,

Suite à votre retour, j’ai préparé une première proposition concrète de landing GeeN, alignée avec vos références (plus épurée, moins de mouvements, globe animé conservé).

Je vous partage :
- une version desktop/mobile,
- une courte démo vidéo,
- et une note UX expliquant les choix de structure.

L’idée n’est pas encore de tout refaire, mais de montrer une base claire, crédible et immédiatement actionnable pour la suite.

Bien à vous,
Manoah
